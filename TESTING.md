# Проверки сборки

- Python 3.12, aiogram 3.31.0, python-dotenv 1.2.2.
- `python -m unittest discover -s tests`: 117 тестов, OK.
- `python checks/offline_checks.py`: 7 тестов, OK.
- Python-файлы проверены синтаксическим разбором.
- Токен и ID владельца/основных чатов в `.env` совпадают с исходными настройками.
- `data/bot.sqlite3` побайтово совпадает с базой в исходном архиве.
- Настоящий токен присутствует только в `.env`, из кода и JSON убран.
- Из выходного ZIP исключены старые логи, кэш Python, JSON-конфиги и устаревшие инструкции установки.

Регрессии настроек проверяют запуск без `.env`, оба имени токена, алиас ID владельца, приоритет окружения над файлом, некорректные значения, привязку каналов, сохранение комментариев, атомарность записи и ошибки записи. Проверки действий бота используют настоящий Dispatcher aiogram и подмену ответов Telegram. Старые тестовые ответы обновлены для пересылки публикаций и текущего интерфейса.

Реальный polling Telegram и запуск на Android/Pydroid в этой среде не выполнялись. Установленные зависимости не включены в архив: они устанавливаются из `requirements.txt`.
