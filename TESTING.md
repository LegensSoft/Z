# Проверки текущего обновления

Команда: `python -m unittest discover -s tests -v`.

17 тестов: строгая проверка skip FlyerHubs, ошибка API, отсутствие утечек ключа в ошибках, повторная проверка на следующем действии, совместная проверка каналов, пропуск владельца, сохранение настройки, запрет пропуска обычному пользователю, middleware, построение роутеров и настройки из .env.

Проверены синтаксис всех Python-файлов и импорт модулей. База data/bot.sqlite3 сохранена побайтно относительно присланного Z-main.zip. Тесты используют временные базы и подменённые ответы Telegram/FlyerHubs.

В архиве пользователя не было старых тестов, несмотря на упоминание 117 проверок в прежнем TESTING.md. Этот файл описывает только проверки, реально выполненные для данного обновления.

Реальный polling Telegram, запросы с личным ключом FlyerHubs и запуск в Pydroid 3 не проверялись.
